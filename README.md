# AI-Based Resume Screening System

## Description
An AI-powered Resume Screening System using NLP and Sentence Transformers to rank resumes based on job description similarity.

## Features
- Resume Parsing
- NLP Preprocessing
- Sentence Transformer Embeddings
- Cosine Similarity Matching
- Resume Ranking
- Skill Extraction
- Missing Skills Detection

## Technologies Used
- Python
- NLTK
- Sentence Transformers
- Scikit-learn
- Pandas
- Matplotlib

## Workflow
1. Upload Resumes
2. Extract Text
3. Preprocess Text
4. Generate Embeddings
5. Compute Similarity
6. Rank Candidates

## Installation

```bash
pip install -r requirements.txt
```

## Run
Open notebook in Google Colab or Jupyter Notebook.

## Output
- Resume Ranking
- Match Score
- Skills Found
- Missing Skills
